# Global Official Business Facts

One directory of official business-registry links, plus one paid live lookup interface where automation is available.

Human use:

- open the homepage
- choose a jurisdiction
- follow the official registry link

Machine use:

- read `/jurisdictions.json`
- check `lookupAvailable`
- use `/api/v1/business/lookup` when supported

The directory is free. Automated lookup is priced separately.

This repository keeps official-source research and adapter evidence internally, but the public website intentionally stays small.
